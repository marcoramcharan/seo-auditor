seo-auditor

A Node.js tool that crawls a locally hosted site and audits its SEO health.

The plan

  1. Get a sitePick the site to audit. Copy it onto the desktop and serve it locally (for example npx serve ~/Desktop/site).
  2. Crawl it locally with Node.jsStart at the local server root and follow internal links only.
  3. Collect all page pathsGather every /index.html page path found, then list those paths as the master page inventory.
  4. Check for broken linksTest every internal and external link, flag 404s, 5xx and redirect chains.
  5. Check canonicalsVerify each page has a <link rel="canonical">, it is absolute, self-referencing where expected, and not pointing at a broken page.
  6. Check meta descriptionsMissing, duplicate, too short or too long (aim for roughly 70 to 160 characters).
  7. Check technical SEOTitle tags, H1 count, lang, viewport, robots meta, image alt text, sitemap.xml, robots.txt, structured data.
  8. Analyse link clustersFind which pages have strong internal linking, which are orphans, and which are weakly linked.

Checks at a glance

CheckWhat it looks forOutput
Page pathsAll discovered /index.html pagesPath list
Broken linksNon-2xx responses, redirect chainsLink, source page, status
CanonicalsMissing, relative, mismatched, duplicatedPer-page verdict
Meta descriptionsMissing, duplicate, bad lengthPer-page verdict
Technical SEOTitles, H1, alt text, robots, sitemapIssue list by severity
Link clustersInbound and outbound internal links, orphansRanked pages

Suggested structure

seo-auditor/
  package.json
  src/
    crawl.js        # fetch pages, extract links, build the page graph
    checks/
      links.js      # broken links
      canonical.js  # canonical tags
      meta.js       # meta descriptions and titles
      technical.js  # other technical SEO checks
      clusters.js   # internal link graph analysis
    report.js       # write results to JSON and HTML
  reports/

Tooling ideas

  • fetch (built into Node) for requests
  • cheerio for parsing HTML
  • p-limit to keep the crawl polite and concurrent
